# Finley — Personal Finance Dashboard

A small personal-finance dashboard: account overview with summary stats,
a searchable/sortable transaction history, and per-category budgets.
All data is seeded in the repo (no backend, no auth), so the app renders
deterministically on every run.

Built with React 18, TypeScript, Tailwind CSS 4, and Vite. Tests run on
Vitest + React Testing Library.

## Run it

```bash
npm install
npm run dev     # http://localhost:5173
```

## Test it

```bash
npm test
```
