# Searching transactions

The Transactions page includes a search box and a category filter above the table.

## How search works

Type a merchant name or a category into the search box. The table updates as you
type with the matching transactions. To search for something else, clear the box
and enter a new term.

Searches match against the merchant name and the category of each
transaction. Amounts and dates are not searched.

## Category filter

Use the **All categories** dropdown next to the search box to limit the table to
a single category (for example, Groceries or Dining). Choose **All categories**
again to remove the filter.

The selected category is reflected in the page URL as `?category=…`, so you can
bookmark or share a filtered view. Other query parameters on the URL are
preserved when you change the category.

## Tips

- Searches are case-insensitive.
- Combine search with the category filter to narrow results further.
- Combine search with the column headers to sort the matched results by
  date, merchant, or amount.
